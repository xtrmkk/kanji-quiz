## 大問2・図1（確定）

正六角形は**上下が頂点**（30°・90°…の向き）。中心から3本の対角線が引いてある。
B は左下の頂点（210°）、C は真下の頂点（270°）で、**BC は正六角形の1辺**。
A は中心Oと辺BCの中点を結ぶ線の上にあり、**∠BAC＝120°、AB＝AC**。

外接円の半径をRとすると（1辺もR）

- A は O から 240°の向きに **R/√3**（中心から辺の中点までの 2/3 のところ）
- **OA ＝ AB ＝ AC ＝ R/√3**。図ではこの3本に等しさの印が付いている
- 三角形ABCの高さは √3R/6、面積は √3R²/12。正六角形は 3√3R²/2 なので **18倍** ✓
  （＝「正三角形OBC の 1/3」。これが公式解答の筋道）

## 大問2・図2（確定）

四角形ABCD は **B 左下・C 右下・D 右上・A 左上**のとても平たい形。
BC を1とすると A＝(0.5, √3/6)、D＝A＋(1/√3, 0)。対角線 AC・BD も引いてある。
∠BAC＝120°、AB＝AC＝AD、AD∥BC。∠DBC＝**15度**。

一般に ∠BAC＝θ のとき ∠DBC＝(180−θ)/4。θ＝120 で 15°。

## 大問2・図3（確定）— ここが肝

正六角形ABCDEF は図1と同じ向きで、**A が真上（90°）、以下 B150°・C210°・
D270°・E330°・F30°**（反時計回り）。

内側の正六角形PQRSTU は、**外側と同じ中心で、15°回した、半径 √(2/3) 倍**。
頂点は P105°・Q165°・R225°・S285°・T345°・U45°（いずれも半径 √(2/3)R）。

図に引いてある線は**6本だけ**で、どれも
「外側の頂点 → 内側の頂点 → となりの内側の頂点」が**一直線**になっている。

    A(90°) → P(105°) → Q(165°)
    B(150°) → Q(165°) → R(225°)   …以下60°ずつ回したもの

この6本と6辺で、正六角形は **内側の正六角形＋合同な三角形6つ**にきっちり分かれる。
三角形は（B, C, R）のような形で、**1辺BCを底辺、高さは √3R/6** ＝ 図1の三角形と同じ。

- B のところに **15°** の印（辺BC と 線BR のなす角）。A では 辺AB と 線AQ のなす角が15°
- 三角形1つは正六角形の 1/18、6つで 1/3。内側の正六角形は **1 − 1/3 ＝ 2/3倍** ✓
- (1)(2)(3) はつながっている。(2)の「AD∥BC だから ∠DBC＝15°」が、
  (3)の「15°の線の先は、図1のAと同じ高さの線の上」＝「三角形の面積は図1と同じ」の根拠になる
