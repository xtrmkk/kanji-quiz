## 大問ごとの中身

### 1（虫食い算・60%・5点）
次の式が成り立つとき、整数ア、イ、ウにあてはまる1けたの整数の組み合わせをすべて答えなさい。
ただし、アはイ以下の整数であるものとします。また、答のらんはすべて使うとは限りません。

> 2［ア］2 × 2［イ］2 ＝ 44［ウ］44

答欄は ア／イ／ウ の3列の表で、行が複数（使い切らなくてよい）。
解説：3けたで百の位と一の位が2の数は 202, 212, …, 292。答は44044以上45000未満。
232以上だと 202×232＝46864 で45000を超えるので、2つの数は 202, 212, 222 のいずれか。
アはイ以下なので調べるのは6通り。202×222＝44844、212×212＝44944 が条件に合う。

### 2（砂糖水・濃度）
5%の砂糖水80gに2%の砂糖水をAg、11%の砂糖水をBg加えて混ぜると濃さ6.625%の砂糖水Pができた。
また5%の砂糖水80gに2%の砂糖水をBg、11%の砂糖水をAg加えて混ぜると濃さ5.875%の砂糖水Qができた。
（砂糖水の濃さ＝砂糖水の重さに対する砂糖の重さの割合）

- (1) PとQを混ぜ合わせると何%か。90%・2点 → **6.25%**（PとQの濃さの平均。重さが等しいから）
- (2) A、Bを求めなさい。18%・4点 → **A=180, B=220**
  - 和：(6.625+5.875)/2 = 6.25% が 80+A+B の濃さ → 砂糖 8g+0.13(A+B) = 0.125(80+A+B) → A+B=400
  - 差：(6.625−5.875)% × (80+A+B) = 0.09×(B−A) → B−A=40

### 3（缶詰・場合の数）
ある小学校のフードドライブで、5年生の4つのクラス（1組〜4組）で合計15個の缶詰が集まった。
缶詰が0個のクラスがあってもよい。

- (1) 1組が9個のとき、残り3クラスの集まり方。70%・3点 → **28通り**（残り6個を3つに＝₈C₂）
- (2) どのクラスも1個以上のとき。32%・4点 → **364通り**（₁₄C₃）
- (3) どのクラスも1個以上8個以下のとき。6%・5点 → **284通り**（364 − 4×₆C₃）

### 4（速さ・すれちがい）
P地点とQ地点を結ぶ600mのまっすぐな道。太朗君は自転車、次朗君は分速50mで歩いて
同時にP地点を出発し、P・Q間を休まず24分間進む。一定の速さで、P・Qに着くとすぐ折り返す。
「すれちがう」＝反対方向から向かい合って進んできた2人が出会うこと。

- (1) 太朗君が分速180mのとき、すれちがう地点は何か所。56%・3点 → **4か所**
- (2) 太朗君が分速250mのとき、すれちがった地点はPから何m。49%・4点 → **200m, 400m**（答欄3つ・全部は使わない）
- (3) 全部で9回すれちがう太朗君の速さの範囲。13%・4点 → **分速400mより大きく、分速450m未満**
  - 「以上／より大きく」「以下／未満」を○で囲む形式

次朗君は 50×24＝1200m＝ちょうど往復1回ぶん、というのがこの問題の骨。

### 5（長方形の台紙・重なり）
たて11cm、横12cmの長方形の台紙ABCD（A左上・B左下・C右下・D右上）。
別の2枚の合同な長方形をはりつける。たても横も整数、正方形は長方形に含まない。
1枚は左の辺が辺ABに・上の辺が辺ADに重なるように（左上）、
もう1枚は右の辺が辺DCに・下の辺が辺BCに重なるように（右下）。
図2は2辺5cm・10cmの例で、重なりは12cm²（左上が横10×たて5、右下が横5×たて10）。

重なり＝（左上の横＋右下の横−12）×（左上のたて＋右下のたて−11）

- (1) 2枚を同じ向きに置いて重なりが30cm²。32%・4点 → **2通り**
  - (2p−12)(2q−11)=30。重なりのたては奇数・横は偶数なので 3×10 と 5×6 → (横,たて)=(11,7),(9,8)
- (2) 左上の長方形を横の向きにして置いて重なりが30cm²。4%・5点 → **5通り**
  - 直角向き（左上が横長・右下がたて長）なら (p+q−12)(p+q−11)=30 → 連続する2数の積 5×6 → p+q=17
    → (6,11)(7,10)(8,9) の3通り
  - **公式解説はここに (1) で求めた2通りを足して 5通り としている**（＝(8,9)が重複して数えられている）。
    解説 p08「以上から、2辺の組み合わせは (ウ、エ)=(6,11)… (1)で求めた2通り…」。
    練習テストは公式解答に合わせるので、**答え(2) ＝ |同じ向きの解| + |直角向きの組| と定義する**。

### 6（ふるい・規則性）
1から順に600まで整数を横に6個ずつ並べた表（100行）。左からA列…F列。

- (1) 「1」を消し、次に「2以外の2の倍数」と「3以外の3の倍数」を消す。
  同じ行に残っている2つの数の和がちょうど354になるのは何行目か。79%・4点 → **30行目**
  （各行に残るのは A列=6n−5 と E列=6n−1。和は 12n−6。和差算で 175 と 179）
- (2) 続けて「5以外の5の倍数」を消す。2つの数だけが残っている行は何行。49%・4点 → **60行**
- (3) (2)のとき表に残っている数は全部で何個。35%・4点 → **162個**
- (4) (2)に続けて「7以外の7の倍数」を消す。2つの数だけが残っている行は何行。4%・5点 → **44行**
